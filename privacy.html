Privacy

This Website

This public website does not collect personal data beyond standard web server logs. We do not run analytics trackers, advertising pixels, or behavioral profiling of any kind.

The BlocNav Application

BlocNav's application platform is currently in private pilot evaluation. Within the application:

  • An email address is collected at login for user identification and data attribution
  • POI data, coverage polygons, and GPS track logs created by users are stored locally on-device and synced to a PostGIS database when connectivity is available
  • GPS track logs record movement paths (coordinates, distance, duration) only while actively recording — tracking does not run in the background
  • Location data is used for map positioning and track logging, and is not transmitted beyond the user's device unless explicitly attached to a POI or track
  • No data is sold, shared with third parties, or used for advertising

Design Principles

BlocNav is built around local data ownership and minimal collection. Data created in the field belongs to the team that created it. We collect only what is necessary for the application to function — nothing more.

Data Handling

Specific data handling practices within the application depend on deployment context and are governed by pilot agreements with participating organizations. If you have questions about how your data is handled, contact us at contact@blocnav.com.
